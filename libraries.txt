Install these libraries before compiling the project. The repository setup scripts install the pinned Arduino Library Manager names listed below.

## Board Core

- `arduino:samd`
  - Target board: Arduino Nano 33 IoT
  - FQBN: `arduino:samd:nano_33_iot`

## Required Libraries

- `Arduino_SpiNINA@0.0.2`
  - Required by the Nano 33 IoT WiFi stack.
- `WiFiNINA@2.0.1`
  - WiFi connectivity for the Nano 33 IoT.
- `Sensirion Core@0.7.3`
  - Dependency for Sensirion SHT libraries.
- `Sensirion I2C SHT3x@1.0.1`
  - SHT31/SHT3x temperature and humidity sensor support.
- `Adafruit BusIO@1.17.4`
  - Required by RTClib for I2C device helpers.
- `Adafruit Unified Sensor@1.1.15`
  - Required by the Adafruit TSL2591 light sensor library.
- `Adafruit TSL2591 Library@1.4.5`
  - CQrobot CQRTSL25911 / TSL25911 cabinet illuminance sensor support.
  - Used only for measurement and Home Assistant publishing in the initial integration.
- `RTClib@2.1.4`
  - DS3231 RTC and alarm support.
- `PubSubClient@2.8.0`
  - MQTT client dependency used by ArduinoHA.
- `home-assistant-integration@2.1.0`
  - Home Assistant MQTT integration by Dawid Chyrzynski.
- `ArduinoOTA@1.1.1`
  - OTA upload support for planned system and diagnostic tests using the JAndrassy ArduinoOTA library.
  - No additional Arduino Library Manager dependencies are required by this library.
- `AD5263@0.1.4`
  - AD5263BRUZ50 dimmer control via I2C.
  - The library is still in an early/test phase; project-specific adjustments may be required.
  - Project-specific additions or additional library functions may be required for the readback/plausibility checks required by the specification for fault detection.
- `JC_EEPROM@1.0.10`
  - Access to the external **AT24C32 EEPROM** of the WINGONEER Tiny DS3231 AT24C32 I2C module.
  - This library is fixed for the project.
- `Streaming@6.3.0`
  - Required by **JC_EEPROM**.

## Intentionally No Longer Used

- `SAMD_SafeFlashStorage`
  - Persistence is no longer stored in the internal flash of the Nano 33 IoT.

## Notes

- Create local `sketches/alpha/Smaeenhouse/Credentials.h` from `sketches/alpha/Smaeenhouse/Credentials.example.h`.
- Do not commit `Credentials.h`.
- When changing dependencies, update all of these together:
  - `libraries.txt`
  - `sketches/alpha/Smaeenhouse/sketch.yaml`
  - `scripts/setup-arduino.ps1`
  - `scripts/setup-arduino.sh`
